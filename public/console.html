屏蔽网站 0

把域名指向不可用地址实现屏蔽。每条域名同时写入 0.0.0.0 与 ::， IPv4 与 IPv6 都无法访问——只写一族的话，双栈机器换另一族照样能连。
支持批量粘贴（每行一个，也可直接贴网址）。被屏蔽的域名不参与优选，也不会出现在 hosts 的优选区与广告区。
内置屏蔽规则 0 条随代码生效，不在下方列表里显示；这里只列你手动添加的。

域名规则查询

模糊匹配某个域名落在哪条规则里。三种匹配方式：
包含 子串命中，如 github → github.com、api.github.com； 正则 写 JS 正则片段，如 ^api\..*\.com$； 占位符 用 * 任意串、? 单字符，如 *.github.com、cdn.*.net。
