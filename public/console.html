真实延迟分解

把一次 HTTPS 请求拆成 DNS / TCP / TLS / 首字节四段。能连上不等于能握手成功，TLS 段最容易被忽略。
支持一次粘贴多个域名（每行一个，也可直接贴网址），逐个检测 SNI；没有阻断的会自动加入自定义域名。

批量刷新与进度

本地没有 subrequest 限制，可一次刷新全部域名。已被判定 SNI 阻断的域名默认跳过。

屏蔽网站 0

把域名指向不可用地址实现屏蔽。每条域名同时写入 0.0.0.0 与 ::， IPv4 与 IPv6 都无法访问——只写一族的话，双栈机器换另一族照样能连。
支持批量粘贴（每行一个，也可直接贴网址）。被屏蔽的域名不参与优选，也不会出现在 hosts 的优选区与广告区。
